# خدماتي | Khadamati

منصة خدمات متعددة المنصات باستخدام Expo وReact Native وTypeScript وExpo Router، بقاعدة كود واحدة للويب وAndroid وiOS.

## الموجود في الواجهة الحالية

- صفحة رئيسية عربية بتصميم متجاوب.
- 14 خدمة رئيسية و14 خدمة مميزة، لكل خدمة صورة ووصف مختصر وتفاصيل.
- صفحة لجميع الخدمات وصفحة تفاصيل مستقلة لكل خدمة.
- صفحة طلب خدمة بواجهة نموذج أولية.
- صفحة من نحن (About).
- شاشة دخول إدارة وصفحة لوحة تحكم لإدارة الأقسام.
- لوحة الإدارة تعرض إضافة وتعديل وحذف الأقسام، وتعديل الاسم والوصف والتفاصيل ورابط الصورة ونوع القسم.

## تنبيه مهم حول الوضع الحالي

هذه المرحلة هي واجهات وتجربة تفاعلية أولية. تغييرات الأقسام داخل لوحة الإدارة محفوظة في حالة الواجهة فقط، ولا تستمر بعد إعادة تحميل التطبيق أو تنتقل إلى أجهزة أخرى. شاشة الدخول لا تتحقق من حسابات فعلية بعد، ونموذج طلب الخدمة لا يرسل طلبات فعلية.

قبل الاستخدام الحقيقي يلزم:
1. ربط Backend وقاعدة بيانات لحفظ الأقسام والصور والطلبات.
2. إعداد مصادقة آمنة وصلاحيات للأدمن، وعدم استخدام بيانات دخول ثابتة داخل التطبيق.
3. ربط نموذج طلب الخدمة وإظهار الطلبات داخل لوحة الإدارة.
4. إعداد تخزين صور مناسب وربط روابطها ببيانات الأقسام.

## التشغيل

```bash
npm install
npx expo install --fix
npx expo start
```

ثم:
- اضغط `w` لتشغيل نسخة الويب.
- اضغط `a` لتشغيل Android.
- اضغط `i` لتشغيل iOS على macOS مع Xcode.

## المسارات

- `/` الصفحة الرئيسية.
- `/services` جميع الخدمات.
- `/service?id=electricity` مثال لتفاصيل خدمة.
- `/request-service` نموذج طلب الخدمة.
- `/about` من نحن.
- `/admin-login` شاشة دخول الإدارة.
- `/admin` معاينة لوحة التحكم.

## البناء

يستخدم المشروع ملفات EAS في `eas.json`. بناء Android وiOS يتطلب إعداد حساب Expo وبيانات التوقيع اللازمة. لم يتم ربط المشروع باستضافة Vercel، ولا توجد عملية نشر تلقائي مضافة من هذه التعديلات.
